The autopsy, in four acts

  1. Act I

    Exhume

    A read-only GitHub App digs up only your lockfiles. No clone, no install, no code run.

  2. Act II

    Identify

    Every body gets a toe tag. Syft names each package and version exactly.

  3. Act III

    Trace the roots

    We follow every root underground: what you chose, and what came along with it.

  4. Act IV

    Pronounce

    Dead is only ever sealed on evidence: a deprecation, an archive, the maintainer's own word.

Six states of being

Alive

Maintained and growing. Nothing to do.

Resting

Finished, not abandoned. Quiet because it is done.

Ailing

Cracks are showing. Worth watching.

Dead

Declared dead on evidence: deprecated, archived or retired by its maintainer.

Cursed

Dead and carrying a known vulnerability. Dig these up first.

Wounded

Still alive, but this version has a known vulnerability.

We don't guess at death

The mortality model was frozen before we drew a fresh, held-out set to test it. On that set, every package it pronounced dead really was dead.

The sample was small, so the formal verdict was inconclusive — and we say so on the stone.
